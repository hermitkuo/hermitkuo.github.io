本月 5 個高訊號變化

排序依據：對 UX 工作方式的結構性影響 × 可立即落地程度 × 是否跨越單一工具。

01 · Highest Signal

設計師正在從「畫介面」轉向「管理 agent 行為」

核心問題不再只是 affordance 與 flow，而是 agent 的任務範圍、授權層級、升級條件、失敗復原與 human override。Agentic UX 越來越像 delegation design。

學習動作：把 autonomy level、approval、handoff、undo、audit trail 納入每個 UX flow。
02 · High Signal

Context 與 Skills 正取代「更會下 prompt」

Figma 2026 的 agent 方向明確把 attachments、connectors、skills、team context 帶入設計流程。真正競爭力逐步從 prompt craft 轉向 context engineering 與可重用工作方法。

學習動作：建立 design principles、component rules、UX heuristics、review checklist 的 reusable skills。
03 · High Signal

Design ↔ Code handoff 正在變成雙向同步

Figma 與 codebase 的互通持續深化：設計不再是最終規格圖，而更像可持續修改、測試與回寫的共享工作空間。UX 要開始理解 production state，而不是只做理想稿。

學習動作：把 real product state、edge cases、data state、permissions 與 responsive behavior 拉回設計評審。
04 · Emerging

Synthetic Research 從 persona role-play 走向 behavioral twin

August 等產品開始用真實行為資料建立 digital twins，並嵌入 Figma、Claude、GitHub review。這可能改變早期研究速度，但證據品質與外部效度仍是主要風險。

學習動作：把 synthetic users 當 hypothesis generator，不要當真實 user research 的替代品。
05 · Operational Signal

UX Research 自己也開始 agent 化

研究者開始將特定 research tasks 做成 agent，顯示 UX 工作不只是在「設計 AI」，也在被 agent 重構。可委派的分析工作會快速增加，但研究 framing 與 interpretation 反而更重要。

學習動作：先自動化 tagging、synthesis、evidence retrieval；保留 sampling、framing、interpretation 給人。

本月判斷：該學什麼／不要追什麼

Radar 的核心不是「知道更多」，而是改變下一個月的學習配置。

值得投入

  • Agent autonomy design：Suggest → Draft → Confirm → Bounded action → Monitor。
  • Failure UX：partial failure、timeout、ambiguous intent、wrong context、recovery。
  • Context engineering：role、state、history、data provenance、policy、skills。
  • Design × code literacy：理解 state、component、API、responsive、production constraints。
  • Evaluation UX：task success、decision quality、override、correction burden、time-to-confidence。

Not-to-do

  • 不要把「AI UX」等同於加 chatbot。
  • 不要把 prompt engineering 當長期核心職能。
  • 不要用 synthetic user 取代真實研究樣本。
  • 不要花大量時間追單一 UI aesthetic trend。
  • 不要讓 agent autonomy 由 model capability 決定；應由風險與可逆性決定。

下月追蹤問題

真正值得 Radar 繼續追的是可驗證的結構性變化。

Agent UX pattern 是否收斂？

觀察 autonomy ladder、approval UI、audit trail、recovery pattern 是否跨產品形成共識。

Design skills 是否變成新 design system layer？

若 team skills 能穩定承載 taste、rules 與 QA，design system 將從 component library 擴展為 agent-readable operating system。

Synthetic research 能否通過真實 user validation？

關注 digital twin 與實際人類行為的一致性、calibration、segment drift 與 failure cases。

Designer 的產能衡量是否改變？

從 screens shipped 轉向 decision quality、cycle time、rework reduction 與 cross-functional throughput。
