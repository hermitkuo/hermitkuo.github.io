UX / Agentic UX Radar

2026-10-01｜覆蓋 9/1–9/30。Agent 開始常駐、跨 channel、在背景工作並擁有分層授權。UX 的新核心：context、delegation、activity visibility、evaluation、recovery。

本月判斷

上月是 production is cheap; judgment is scarce；本月進一步成為 persistent delegation。

Agentic UX is becoming an operating model. 介面要定義 agent 知道什麼、能做什麼、何時問人，以及人在何處看見與收回控制權。

6 個高訊號

依結構性影響 × 成熟度 × 可落地性排序。

01 · HIGHEST

Activity View 成為新主畫面

dots 可 24/7 工作、跨 ChatGPT/Slack/Teams 延續 context，並主動回報進度與決策點；長任務主畫面不再只是 chat。

做：顯示 goal / next action / blocked reason / last decision / stop。
02 · HIGHEST

Progressive autonomy 成形

dots 將 proactive research 預設為 read-only；高影響 action 再經 rules、review、approval。

做：Read → Draft → Propose → Execute → Sensitive 五級 authority ladder。
03 · HIGHEST

長任務 agent 基礎設施化

Agents API 將 context、tools、subagents、hosted environment 與長任務週期產品化。

做：Queued → Working → Needs input → Review → Done / Partial / Failed。
04 · HIGH

Context engineering 進入 UX

NN/g 將 context 分成 global、local、ambient；它成為有 scope、freshness、權限的產品層。

做：在 journey map 旁加 Context Map。
05 · HIGH

從選模式轉向表達意圖

Anthropic 將 chat 與 Cowork 收斂到單一介面；使用者不該理解內部 mode taxonomy。

做：減少 AI mode 選單，保留 capability disclosure 與 override。
06 · HIGH

Design system 變成 agent contract

Figma MCP 持續朝 code↔canvas round-trip 前進；agent-readable 開始變 agent-writable。

做：檢查 naming、token binding、variant rules、read/write scope。

Research / Not-to-do

研究方法與投資取捨一起看。

值得做

  • AI prototype 提早測 behavioral fidelity、state、edge cases。
  • 用 PACED：Policy/Audience/Context/Expectations/Degree 決定 AI disclosure。
  • 保存 edit / override / reject reason / rubric correction；TAHI 顯示這些可成為 personalization data。

不要追

  • Chat-first everything。
  • 一個 super-agent 擁有全部權限。
  • 要求使用者理解所有 AI mode。
  • 用 personality 取代透明度與可逆性。
  • 把 prototype / synthetic users 當真實研究證據。
